# RooflineAI

RooflineAI builds a retargetable compiler SDK that lets hardware vendors and embedded software teams deploy and optimize AI/ML models on edge devices (NPUs, MCUs, heterogeneous SoCs) without manual tuning. Built on open-source MLIR/IREE with proprietary hardware-specific optimization on top.
